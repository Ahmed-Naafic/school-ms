# Saxaab website UI kit

Marketing site for Saxaab (ICT services). No existing product source was provided, so this kit is an **original proposal** built strictly from the design system tokens/components — not a recreation.

- `index.html` — full interactive page: header (sticky), hero, services grid, why-Saxaab band, contact form (fake submit → toast), footer.
- `Icons.jsx` — Lucide icon paths copied inline (shared).
- `Header.jsx`, `Hero.jsx`, `Services.jsx`, `WhySaxaab.jsx`, `Contact.jsx`, `Footer.jsx` — sections.

Composes the system components (`Button`, `Card`, `Badge`, `Input`, `Select`, `Toast`) from `_ds_bundle.js`.
