Pill-shaped action button; use `primary` (navy) for the main action, `secondary`/`outline` beside it.

```jsx
<Button variant="primary" size="md" onClick={...}>Talk to us</Button>
<Button variant="secondary">Get a quote</Button>
```

Variants: primary (navy), accent (teal), secondary (teal tint), outline, ghost. Sizes sm/md/lg. Verb-first labels, sentence case.
